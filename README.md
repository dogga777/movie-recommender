# 🎬 Movie Recommendation Engine

## 📝 Project Description

This is a Content-Based Movie Recommendation System built with Python.

It uses **Natural Language Processing (NLP)** to analyze movie tags and **Cosine Similarity** to suggest movies based on user interest.

---

## 🚀 How to Run

### 1. Install Required Libraries

```bash
pip install pandas scikit-learn
```

### 2. Run the Recommendation Engine

```bash
python recommend.py
```

---

## 🛠️ Tech Stack

- Python → Core logic
- Pandas → Data manipulation
- Scikit-Learn → Vectorization and similarity calculations
- Pickle → Model serialization

---

## 📊 Dataset

This project uses the TMDB 5000 Movie Dataset.

The dataset includes:
- Movie titles
- Genres
- Keywords
- Plot summaries
- Cast and crew metadata

---

## 👨‍💻 Features

- Content-based movie recommendations
- Cosine similarity matching
- Fast recommendation retrieval
- Clean modular project structure
- Debugging and optimization workflow
